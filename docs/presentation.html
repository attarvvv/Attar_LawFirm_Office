Attar Lawfirm Office — Dokumen Presentasi Proyek Bagian 1: Ringkasan & Alur Sistem

1. Ringkasan Eksekutif (Executive Summary)

Konsep Platform Dua Sisi (Two-Sided Platform)
Attar Lawfirm Office menggabungkan kehadiran digital profesional firma hukum untuk publik (*Public Showcase & Online Consultation*) dengan portal internal berbasis peran (*Role-Based Access Control*) untuk pengelolaan jadwal janji temu perkara, penugasan advokat, notifikasi otomatis WhatsApp, tata kelola artikel, dan manajemen akun staf secara terpusat.

2. Alur Keseluruhan Sistem (End-to-End System Flow)

A. Alur Publik (Calon Klien)
1
Eksplorasi Landing Page
Klien menelusuri layanan hukum, profil advokat, artikel edukasi, dan legal credentials kantor hukum.
2
Formulir Konsultasi Online
Klien mengakses menu Konsultasi Sekarang (/konsultasi) dan mengisi data identitas, nomor WhatsApp, serta pokok perkara.
3
Pencatatan Tiket Konsultasi
Data tersimpan ke tabel consultations dengan status awal unread dan timestamp otomatis.
B. Alur Portal Internal (Staf & Advokat)
1
Autentikasi Aman
Staf & advokat login melalui /login dengan JWT dan HttpOnly Cookie. Registrasi publik ditutup total.
2
Verifikasi & Konversi Jadwal
Staf menelaah perkara, lalu mengonversi konsultasi masuk menjadi berkas janji temu resmi (Appointments).
3
Notifikasi Otomatis WhatsApp
Dengan satu klik, bot Baileys mengirimkan surat konfirmasi resmi ke nomor WhatsApp klien secara instan tanpa biaya API.

Struktur Arsitektur Sistem Terintegrasi

Lapisan (Layer) Teknologi Terpasang Fungsi Utama
Client Layer (Frontend) React 19, Vite, Tailwind CSS, React Router v7 Single Page Application (SPA), interaktif, responsif desktop & mobile drawer.
API Layer (Backend) Node.js, Express.js RESTful API, Multer Routing modular, middleware autentikasi RBAC, upload multipart/form-data.
Integration Layer @whiskeysockets/baileys, Sharp, Pino Koneksi persistent WebSocket WhatsApp Web, kompresi gambar otomatis ke WebP.
Data Layer (Database) MySQL (mysql2 pool dengan prepared statements) Penyimpanan relasional: users, consultations, appointments, lawyers, articles.

3. Daftar Library & Framework yang Digunakan

Setiap pustaka dan kerangka kerja dipilih berdasarkan pertimbangan performa, skalabilitas, dan stabilitas operasional:

Modul / Library Kategori Alasan Pemilihan & Manfaat Teknis
React 19 & Vite 6 Frontend Waktu rendering super cepat, hot-module-replacement instan saat pengembangan, dan bundle produksi teroptimasi.
Tailwind CSS 3 Styling Memungkinkan styling responsif presisi tanpa file CSS bertumpuk, palet khusus Deep Forest (#14342B) & Gold (#C2A878).
Express.js 4 Backend Kerangka kerja mikro yang matang, minim overhead, dengan ekosistem middleware luas dan performa I/O tinggi.
MySQL2 (Pool Promises) Database Mendukung koneksi pooling asynchronous dan prepared statements untuk mencegah eksploitasi SQL Injection.
JWT & Bcrypt.js Keamanan Enkripsi kata sandi menggunakan salted hash bcrypt (10 rounds) dan otorisasi sesi stateless terproteksi.
Baileys (@whiskeysockets) WhatsApp Mengoperasikan protokol WebSocket WhatsApp Web secara native tanpa browser berat (Chromium/Puppeteer), hemat memori >80%.
Sharp & Multer Media Kompresi gambar beresolusi tinggi otomatis menjadi format WebP berbobot kecil (<150 KB) untuk menghemat ruang penyimpanan.

4. Kelebihan & Nilai Jual Utama (Unique Selling Points)

1. Integrasi WhatsApp Native (Zero-Cost)
  • Tidak membutuhkan biaya bulanan atau tagihan per pesan dari penyedia third-party.
  • Dilengkapi deteksi error otomatis (463, 515 restartRequired) dan fitur reset sesi instan.
  • Pesan konfirmasi dikirim otomatis dengan template resmi berformat kop digital.
2. Role-Based Access Control (RBAC) Ketat
  • Administrator: Kontrol penuh, kelola staf/pengacara, hak audit sistem.
  • Pengacara: Akses jadwal janji temu dan penerbitan draf edukasi hukum.
  • Staf: Penanganan berkas konsultasi masuk dan konfirmasi temu.
  • Registrasi publik ditutup total untuk menjamin integritas portal internal kantor hukum.
3. Desain Eksklusif & User Experience (UX)
  • Identitas visual formal, bersih, dan berwibawa khas kantor advokat papan atas.
  • Sidebar adaptif (bisa diciutkan menjadi icon-rail) dengan persistensi status di LocalStorage.
  • Pencarian instan dan tab filter cepat di setiap modul manajemen.
4. Keamanan & Perlindungan Data Berlapis
  • Proteksi akun: sistem mencegah penghapusan akun administrator terakhir.
  • Integritas relasi: akun tidak bisa dihapus jika masih terikat data perkara atau artikel aktif.
  • Penyimpanan kata sandi searah (*irreversible hash*) yang tidak dapat dibaca dari database.

5. Kekurangan / Keterbatasan & Rencana Masa Depan

Menjelaskan keterbatasan sistem secara jujur dan memberikan solusinya akan menunjukkan kematangan analisis proyek di depan penguji/klien:

Keterbatasan Saat Ini Dampak Operasional Rencana Pengembangan (Roadmap)
Ketergantungan Ponsel Host WhatsApp Ponsel admin yang discan harus tetap memiliki koneksi internet aktif agar bot dapat bekerja. Mengintegrasikan failover cadangan ke SMS Gateway atau Cloud WhatsApp API resmi untuk kebutuhan skala besar.
Ketiadaan Client Dashboard Klien hanya menerima kabar via WhatsApp/Email tanpa dashboard pelacakan mandiri. Menyediakan portal mandiri klien (Client Case Tracking Portal) dengan login kode tiket unik.
Penyimpanan Bukti Fisik Formulir konsultasi baru menampung pokok perkara dalam bentuk teks deskripsi. Menambahkan fitur upload dokumen perkara (PDF berkas gugatan, scan KTP, alat bukti) dengan enkripsi data terpusat.
Pembaruan Status Realtime Perubahan data baru di dashboard memerlukan aksi pemuatan ulang (*refresh/polling*). Mengintegrasikan WebSocket / Server-Sent Events (SSE) agar notifikasi permohonan baru langsung berbunyi secara realtime.
